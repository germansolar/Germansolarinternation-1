# German Solar International — C&I Solar PV & BESS Microgrid Platform

A corporate web application for **German Solar International**, showcasing Tier-1 commercial, industrial, and utility-scale solar PV and battery energy storage solutions (BESS) across East and Southern Africa (Kenya, Botswana, Rwanda).

## Key Features
- **Turnkey Energy Capabilities**: Commercial & Industrial BESS, Solar PV & Hybrid Microgrids, Zero-CAPEX PPA models, and 10-Step EPC Roadmap.
- **Interactive SCADA Microgrid Telemetry Simulator**: Live three-mode operational simulation (Solar Peak, Grid Outage, Peak Shave).
- **Engineering Sizing & ROI Calculator**: Automated PV kWp and BESS kWh sizing tool with USD/KES tariff and diesel displacement analytics.
- **African Footprint & Case Studies**: Demonstrated engineering projects across Kenya, Botswana, and Rwanda with full technical single-line specs.
- **Hardware Portfolio**: Comprehensive catalog of containerized BESS (500 kW / 1 MWh), industrial cabinets (125 kW / 261.2 kWh), and commercial outdoor ESS units.
- **Full-Page Architecture**: Immersive full-screen takeovers for all datasheets, case studies, and engineering proposals.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Motion

## Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, yarn, pnpm, or bun

### Installation
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build
```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
